# LinkedIn project description

**Title:** AI Code Review Assistant

**Description (paste into the Projects section):**

A full-stack tool that reviews source code for security and maintainability problems and explains each finding: what is wrong, why it matters, and how to fix it. Paste code into a web editor or run the command line tool on a file or staged Git changes, then filter results by severity and reviewer and export an HTML or JSON report.

Two AI reviewers return structured, validated findings through any OpenAI-compatible API (bring your own key). A clearly labeled, rule-based demo mode works with no key, so anyone can try it.

Built with Python, FastAPI, Pydantic, React, TypeScript, Tailwind CSS and Docker. Tested with pytest, Vitest and Playwright; linting and tests run in GitHub Actions. Security work includes path-traversal protection for file tools, API-key redaction from logs, escaped reports, input limits and rate limiting.

Started as a course assignment (AIP444) and extended into a web application with an API, a UI, a test suite and CI.

**Skills to tag:** Python, FastAPI, REST APIs, React, TypeScript, Tailwind CSS, pytest, Playwright, GitHub Actions, Docker, Large Language Models, Application Security
